# 気体あて（kitai-ate）

気体の性質（色・におい・水へのとけ方・確かめ方・集め方）を見て、酸素・二酸化炭素・水素・アンモニア・窒素のどれかを当てる1日5問の学習ゲーム。正解したら「空気と比べて重さは？」（空気より重い・空気より軽い・ほぼ同じ）も選ぶ。中学1年理科「身のまわりの物質」。
